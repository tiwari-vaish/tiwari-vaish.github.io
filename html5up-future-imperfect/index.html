Cleantech ReAct Agentic AI System

Python · LlamaIndex · GPT-4o-mini · RAG · ReAct Agents

November 2024 Vaishnavi Tiwari

Built a multi-tool ReAct agent using LlamaIndex for specialized cleantech research, with a strict tool hierarchy: internal RAG → web search → reasoning engine → safety guardrail. The RAG foundation used a HuggingFace BGE-Small embedding model with 3,072-token chunks to preserve technical context, augmented by an LLMRerank postprocessor that retrieves k=50 candidates then re-scores to the top 5 using GPT-4o-mini. Custom tools included a live web search, a dedicated reasoning engine for complex synthesis, and an ethical safety guardrail for domain-constrained output. Evaluated using LLM-as-Judge methodology across Faithfulness, Relevance, and Completeness metrics.

Invoice Information Extraction: Transformer Comparison

LayoutLMv3 · Donut · HuggingFace · Tesseract OCR

September 2024 Vaishnavi Tiwari

Benchmarked LayoutLMv3 and Donut transformers on a 10,000-invoice dataset across template-aware and template-agnostic settings. LayoutLMv3 was fine-tuned using Tesseract OCR preprocessing, normalized bounding boxes, and AdamW optimization achieving perfect F1 in template-aware conditions. Donut, an OCR-free encoder-decoder, processed raw images directly into structured JSON output, showing superior robustness to unseen layouts. Evaluated across token-level precision, recall, F1, and Exact Match Accuracy, revealing key trade-offs: LayoutLMv3 excels on familiar templates while Donut generalizes better to new invoice formats.

Refugee Asylum Data Analysis

Python · Scikit-Learn · Random Forest · KMeans · UNHCR Data

March 2024 Vaishnavi Tiwari

Analyzed 34,600 UNHCR records of country-to-country asylum cases to identify nations under high refugee pressure and uncover global displacement patterns. Engineered two key features Total Displaced and Asylum Pressure to capture both raw burden and relative strain on host communities. Trained and compared Logistic Regression, Decision Tree, Random Forest, Gradient Boosting, and Voting Ensemble classifiers, with Random Forest achieving F1 > 0.80 on the high-pressure class. Applied KMeans, Hierarchical, and DBSCAN clustering (silhouette-validated at k=3) to reveal three distinct country profiles: high-capacity nations (USA, Germany), high-pressure low-capacity nations (Lebanon, Uganda), and transitional hubs. Findings translated into concrete policy recommendations for humanitarian resource allocation.
